# CCS Neural Engineering

`CCSNE` provides reusable plotting and analysis utilities derived from manuscript workflows.

## Current scope

- Polarity-focused scientific illustration
- Circular statistics helpers
- Reproducible figure-building utilities for notebooks and scripts

## Core modules

- `CCSNE.illustration`
- `CCSNE.analysis`

See [Installation](installation.md), [API](api.md), and the [Tutorial](tutorials/polarity_tutorial.ipynb).
